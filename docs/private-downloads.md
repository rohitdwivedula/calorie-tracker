# Private file handoff

Personal backups, nutrition audits, eating-history reports and raw user lookup
responses must never be attached to GitHub releases or committed to this repository.
Public releases may contain APKs and synthetic/nonpersonal review material only.

Personal downloads use a separately managed, private service on the host. Its
implementation, tests, service configuration, access link and files live outside
this Android project. Do not add that infrastructure to the app's codebase.
Host-specific operating instructions are maintained with that service outside Git.

Publishing a new app version does not authorize publishing personal files. Keep
backup delivery private even if a repository happens to be private at the time.
