# Compose UI review previews

These images are generated by the Compose interaction tests with Robolectric native
graphics and synthetic food data. They are not screenshots from the user's phone.

- [Today](compose-today.png)
- [Portion entry](compose-portion.png)
- [Calorie log date/time](compose-calorie-time.png)

The portion/complete-flow test uses a 320dp display profile to avoid the documented
Robolectric dialog-with-text-field issue #8460. Other screen tests use a 411dp profile.
The tests also render cooking, history, settings, stats and the Ate dialog under
`app/build/outputs/compose-screenshots/`.
