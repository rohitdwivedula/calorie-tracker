App 1.0.7, versionCode 9 — approved for GitHub release v0.1.7
User authorized publishing the APK and enriched backup together.

Changes:
- Dark application theme, dialogs, forms and system bars.
- Portion slider spans 1–8 servings in quarter-serving steps. Text accepts larger
  quantities and fractional servings. Calories and macros update live.
- Add ingredient launches camera directly with Saved foods/Manual food fallbacks.
  Camera cancellation returns to the dish. Save dish renamed Done cooking.
- History combines actual dish-portion events, direct foods and calorie-only logs,
  newest first, with date groups, HH:mm times, named tiles and kcal/protein/fiber.
  Legacy completion entries are labeled estimates. ListView recycles visible rows;
  UI loads 25 more entries as needed. Record models are assembled in memory from
  authoritative SQLite documents before pagination; this is not a SQL cursor feed.
- Today card displays calories, protein and fiber with coverage/goal information.
- Stats: last 7/30 completed tracked days, per-nutrient daily averages, editable
  daily minimum goals (sodium is a maximum), days met and unknown-day counts.
  These are user targets, not personalized RDAs. Averages and goal counts exclude
  days with missing values for that nutrient; today is excluded.
- OFF lookup retains optional fiber, vitamins and minerals using normalized gram
  fields; displayed micronutrients convert to mg/µg. Optional manual correction.
  Existing snapshots stay unchanged. Missing values are not silently made zero.
- Goals and optional nutrients remain in authoritative JSON database documents
  and are included in portable backups. No derived caches or extra uploads.

- 59 tests passed, zero failures/errors. Added tests cover missing vs zero nutrient
  values, partial coverage, complete-day averages, units, limits and slider range.
- APK signature and 16 KB page zip alignment checks passed.
- git diff --check passed.
